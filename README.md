# かけいぼ — ローカル完結の家計簿アプリ

外部サービスを信用せず、**自分の端末の中だけ**で収支を管理するための家計簿アプリです。
サーバー不要・ビルド不要・外部通信ゼロ。`index.html` をブラウザで開くだけで動きます。

## 使い方

```
git clone <このリポジトリ>
cd calc_app
# index.html をブラウザで開く(ダブルクリックでOK)
```

データはブラウザの localStorage に保存され、外部へは一切送信されません。

## 機能

- 支出・収入の記録(日付 / 金額 / カテゴリ / **支払い方法**(現金・クレカ・Suica・PayPay など)/ 名目)
- 月ごとの明細一覧・月次サマリー(収入・支出・収支)・月送り
- 明細の編集・削除、カテゴリ / 支払い方法 / キーワードでの絞り込み
- グラフ表示(月次推移・支出カテゴリ内訳・支払い方法別支出)— SVG 自前描画・ツールチップ付き
- CSV / JSON エクスポート & インポート(バックアップ・乗り換え自由)
- ダークモード(OS設定に追従)・スマホ対応
